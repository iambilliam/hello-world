# Letterpress Scripture

A mobile prototype for memorizing Bible verses (KJV), styled after the Letterpress typing prototype.

Open `index.html` in a browser (it's built for phone screens). A random verse appears. Type it word by word and press space to set each word in place. Each verse takes three passes:

1. **Full**: every letter is outlined.
2. **Initials**: only the first letter of each word is shown.
3. **From memory**: only blank underlines remain.

Miss a word twice and it's revealed. **New verse** picks another one. The verses are a built-in set of 41 well-known passages.
